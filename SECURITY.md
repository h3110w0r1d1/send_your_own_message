## Reporting a Vulnerability

you may add any details, such as device information, how it works, ect here. All details are anomynous, and you will not get in trouble for reporting. If it gets accepted, two things may happen:
1. if it is deemed an urgent security vulnerbility(especially for other users), a fix will be implemented, and the update will be pushed out asap.
2. if it is deemed a non-urgent security update, you can expect the vulnerbility to be patched next update.
if the vulneribility is declined, you may create a bug issue.
